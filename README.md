# UCI-Online-Retail-Analysis-Project
A data analysis project exploring customer purchases using the UCI Online Retail dataset.

## Overview
This project will explore historical customer purchase timing to support a potential reminder experiment for repeat customers. It will combine a mix of data analysis and behavioral psychology to propose an experiment testing whether a reminder could help encourage another purchase.

## Business Question
Which repeat customers are taking longer than usual to place another order and could be considered for a reminder test?

## Supporting Questions
1. How much time typically passes between a customer's orders?
2. How do order patterns vary across different times of the year?

## Intended Stakeholder
A hypothetical CRM (customer relationship management) marketing manager who is responsible for retention.
